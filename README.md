# סטודיו של הדרה - האפליקציה למשפחה

מסך אחד בטלפון: בוחרים מה רוצים (ריל / רוחבי / רק חיתוך), כותבים מה מצפים לקבל, ולוחצים "להמשיך לשליחה במייל". נפתח ג'ימייל עם הכתובת (info@hadara.digital), הנושא ("לעריכה - ...") והטקסט כבר מוכנים. מצרפים את הסרטון ושולחים. משם ממשיך הצינור של `inbox/` בסטודיו.

**בלי שרת, בלי אחסון, בלי התחברות.** קובץ HTML אחד + manifest + service worker, כמו האפליקציות של ירין ואלמוג. הזהות של השולח היא המייל שלו.

## קבצים
* `index.html`: כל האפליקציה (עיצוב לפי `brand/BRAND.md`: שמנת, ורוד, Assistant).
* `manifest.webmanifest`, `sw.js`: "הוספה למסך הבית" ועותק לא מקוון.
* `icon-*.png`, `favicon-32.png`: בניה הקפיברה (`brand/bnaya-icon.png`) על שמנת. נוצרים מ-`brand/` בסקריפט חד-פעמי, לא צריך לייצר מחדש.
* `logo.png`: עותק של `brand/hadara-logo.png`.

## איך זה פותח את המייל
* טלפון אנדרואיד: `mailto:` ← ג'ימייל.
* אייפון: קודם אפליקציית ג'ימייל (`googlegmail://co`), ואם אין, "דואר" של אפל דרך `mailto:`. שימו לב: ב"דואר" של אפל סרטון גדול נשלח ב-Mail Drop (קישור iCloud), והצינור יודע להוריד רק קישורי דרייב. למי ששולח מאייפון עדיף ג'ימייל.
* מחשב: חלון כתיבה של ג'ימייל בדפדפן.

## פריסה
GitHub Pages, ריפו `hadara-digital/hadara-studio`, מה-branch `main`, תיקיית השורש. כל שינוי: `git add -A && git commit -m "..." && git push` מתוך `app/`. הכתובת: https://hadara-digital.github.io/hadara-studio/

לבדיקה מקומית: לפתוח את `index.html` בדפדפן. ה-service worker עובד רק ב-https או ב-localhost.
